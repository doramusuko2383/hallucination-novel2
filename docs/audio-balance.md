# BGM / SE 音量バランスの確認

全編を通しで聴く前に、音源自体の音量とシナリオで指定した `volume` を一括で数値化できます。

## レポートを作る

`ffmpeg` をインストールした環境で、リポジトリ直下から実行します。

```sh
python3 scripts/audio_balance_report.py
```

`audio-balance-report.csv` には、使用シーン、素材の平均・ピーク音量、`volume` 適用後の推定音量が記録されます。Excel やスプレッドシートで `flag` 列を絞り込むと、優先して試聴すべき箇所を確認できます。

| flag | 意味 |
| --- | --- |
| `CLIP_RISK` | 推定ピークが -1 dB を超える |
| `LOUD` | 推定平均が -10 dB を超える |
| `QUIET` | 推定平均が -40 dB を下回る |
| `MISSING` | シナリオから参照された音源が見つからない |

音楽と効果音の重なり方や、演出上の聞こえ方までは数値だけでは決められません。まずフラグ箇所と BGM / SE が同時に始まる場面を試聴し、最後に重要シーンを実機で確認する運用を推奨します。CSV は確認用の生成物なので、通常はコミット不要です。
